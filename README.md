# This too shall pass.

소리와 함께 즐기는 스트레스 해소용 정적 웹사이트입니다. 이미지와 음원 파일 없이 화면은 WebGL2, 소리는 Web Audio로 전부 실시간 생성합니다.

| No. | 콘텐츠 | 하는 일 |
|---|---|---|
| 01 | 뽁뽁이 | 누르고 그어서 터뜨리기 |
| 02 | 초콜릿 | 한 칸씩 쪼개 캐러멜 드러내기 |
| 03 | 싹 밀기 | 색모래를 밀어내 바닥 드러내기 |
| 04 | 스퀴지 | 비누 거품을 닦아 야경 드러내기 |
| 05 | 스팽글 천 | 쓸어서 뒤집어 숨은 그림 드러내기 |
| 06 | 자석 쇠구슬 | 쇠구슬을 끌어모았다가 놓아 흩뜨리기 |
| 07 | 페인트 롤러 | 벽을 칠하고 마스킹 테이프 떼기 |
| 08 | 글레이즈 | 케이크 위에 거울 글레이즈 붓기 |
| 09 | 보호필름 | 모서리부터 필름 벗기기 |
| 10 | 털 밀기 | 바리캉으로 털을 밀어 줄 내기 |
| 11 | 마블링 | 물감을 떨어뜨려 섞고 종이로 뜨기 |
| 12 | 페로플루이드 | 자석으로 검은 액체를 끌어올리기 |
| 13 | 펜듈럼 종 | 흩어졌다 맞물리는 진자 소리 듣기 |

## 실행

빌드가 필요 없습니다. 아무 정적 서버로 폴더를 열면 됩니다.

```bash
npx http-server . -p 4173
```

## 소리 점검

모든 소리의 피크, 스펙트럼, 꼬리 길이를 수치로 확인합니다.

```bash
node tools/audio-check.mjs
```
